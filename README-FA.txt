فیت‌یار نسخه کامل‌تر — راهنمای فارسی
======================================

این نسخه برای استفاده شخصی ساخته شده و از API پولی یا سرور اختصاصی استفاده نمی‌کند.

اجرای سریع روی ویندوز:
1) فایل ZIP را از حالت فشرده خارج کن.
2) پوشه FitYar-Complete را باز کن.
3) روی index.html دوبار کلیک کن.
4) در اولین اجرا تنظیمات هدف، سطح، تعداد روز و محل تمرین را تکمیل کن.

قابلیت‌ها:
- رابط فارسی راست‌چین و واکنش‌گرا
- برنامه تمرینی نمونه خانه و باشگاه
- ثبت حرکت‌های انجام‌شده و وزنه هر ست
- ثبت جلسه آزاد و جلسه برنامه‌ریزی‌شده
- تاریخچه جلسات و امکان حذف اشتباه
- ثبت وزن با تاریخ و یادداشت
- نمودار ساده وزن و خلاصه آمار
- پیشنهادهای مبتنی بر قوانین، بدون API
- خروجی JSON و بازیابی نسخه پشتیبان
- حذف داده‌ها و بازنشانی تنظیمات به‌صورت جداگانه
- پوسته PWA و فایل‌های آفلاین برای میزبانی روی HTTPS

محدودیت‌های مهم:
- اطلاعات روی همان مرورگر/دستگاه ذخیره می‌شود. اگر داده‌های مرورگر پاک شود ممکن است اطلاعات از بین برود؛ مرتب از قسمت «پشتیبان» خروجی بگیر.
- بازیابی نسخه پشتیبان، اطلاعات فعلی را جایگزین می‌کند.
- برای نصب به شکل برنامه روی اندروید و فعال‌شدن Service Worker، فایل‌ها باید روی HTTPS باشند (یا برای آزمایش روی localhost). دوبار کلیک روی index.html برای تست امکانات اصلی کافی است ولی PWA/offline install را فعال نمی‌کند.
- فونت Vazirmatn از Google Fonts می‌آید؛ بدون اینترنت، فونت جایگزین سیستم استفاده می‌شود.
- پیشنهاد مربی مبتنی بر قوانین ساده است، نه مدل هوش مصنوعی پزشکی یا تحلیل حرفه‌ای.
- برنامه‌های تمرینی نمونه عمومی‌اند. با فرم درست، وزنه سبک متناسب با توانت و گرم‌کردن شروع کن. در صورت آسیب/بیماری با متخصص مشورت کن و در صورت درد غیرعادی تمرین را متوقف کن.

نصب روی گوشی:
1) پوشه را روی یک هاست استاتیک HTTPS قرار بده.
2) لینک index.html را در Chrome اندروید باز کن.
3) منوی سه‌نقطه > Install app یا Add to Home screen.
4) برای نسخه پشتیبان، از منوی داخل برنامه استفاده کن.

این نسخه APK نیست؛ وب‌اپ قابل نصب است. ساخت APK مستقل می‌تواند در مرحله بعد با ابزارهایی مثل Capacitor انجام شود.
