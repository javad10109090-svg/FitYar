فیت‌یار — نسخه وب اولیه
========================
روش استفاده در کامپیوتر:
۱) ZIP را کامل استخراج کنید.
۲) برای عملکرد کامل ذخیره‌سازی و نصب آفلاین، پروژه باید روی localhost یا HTTPS اجرا شود.
۳) اگر Python نصب است، در پوشه پروژه پنجره CMD باز کنید و اجرا کنید:
   python -m http.server 8000
   سپس در Chrome آدرس http://localhost:8000 را باز کنید.
   همچنین می‌توانید فایل‌ها را روی یک میزبان استاتیک HTTPS منتشر کنید.

روش استفاده در گوشی:
۱) فایل‌ها را روی یک میزبان استاتیک HTTPS قرار دهید (برای مثال GitHub Pages یا Netlify).
۲) لینک سایت را با Chrome گوشی باز کنید.
۳) از منوی سه‌نقطه، Add to Home screen / افزودن به صفحه اصلی را انتخاب کنید.
۴) بارگذاری اول نیاز به اینترنت دارد؛ پس از بارگذاری فایل‌های برنامه می‌توان رابط را آفلاین باز کرد.

امکانات:
- پروفایل تمرینی
- بانک اولیه حرکات قابل جست‌وجو و حرکت سفارشی
- ساخت/ویرایش/کپی برنامه هفتگی و پیشنهاد اولیه برنامه
- ثبت ست، وزن، تکرار، زمان، نوع ست، یادداشت و تایمر استراحت
- تاریخچه و رکوردها، داشبورد و نمودار ساده
- ثبت وزن و اندازه بدن، عکس‌های پیشرفت
- پشتیبان JSON و بازیابی

محدودیت‌ها:
- نسخه شخصی و محلی است؛ همگام‌سازی بین دستگاه‌ها و حساب کاربری ندارد.
- بانک حرکات نمونه و قابل توسعه است و تمام دستگاه‌های ممکن را تضمین نمی‌کند.
- عکس‌ها و داده‌ها در مرورگر ذخیره می‌شوند؛ مرتب پشتیبان بگیرید.
- پیشنهادها قواعد ساده‌اند و جایگزین مربی یا توصیه پزشکی نیستند.
- این نسخه باید پیش از استفاده روزمره روی مرورگر و گوشی واقعی آزمایش شود.


نسخه بازطراحی‌شده: بانک حرکات گسترش یافته است و حرکات جدید هنگام اجرای نسخه جدید به‌صورت خودکار به بانک اضافه می‌شوند؛ برنامه‌ها و رکوردهای قبلی در همان مرورگر حفظ می‌شوند. برای دیدن سابقه هر حرکت، در بانک حرکات روی «جزئیات» بزن. بخش جزئیات نشان می‌دهد حرکت در کدام برنامه‌هاست، چه تاریخ‌هایی انجام شده و در صورت داشتن حداقل دو ثبت وزنه، نمودار پیشرفت را نمایش می‌دهد.
